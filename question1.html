1(b) — CSS Box Model

The CSS box model consists of content, padding, border and margin.

  • Content: The text or other material inside an element.
  • Padding: Space between the content and the border.
  • Border: The line surrounding the padding and content.
  • Margin: Space outside the border.
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>CSS Box Model</title>
    <style>
        .margin {
            background-color: red;
            margin: 40px;
            padding: 30px;
            border: 6px solid black;
        }
        .content {
            background-color: grey;
            margin: 20px;
            padding: 30px;
            border: 4px solid blue;
        }
    </style>
</head>
<body>
    <h2>CSS Box Model</h2>
    <div class="margin">
        margin
        <div class="content">
            padding
            <p>content</p>
        </div>
    </div>
</body>
</html>

1(c) — HTML Lists

An ordered list is numbered, an unordered list uses bullets, and a description list contains terms and their descriptions.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>HTML Lists</title>
</head>
<body>
    <h3>Ordered List</h3>
    <ol><li>Registration</li><li>Payment</li></ol>

    <h3>Unordered List</h3>
    <ul><li>Finance</li><li>ICT</li></ul>

    <h3>Description List</h3>
    <dl>
        <dt>HTML</dt>
        <dd>Creates web pages</dd>
    </dl>
</body>
</html>

1(c) — Food for All Initiative

This page introduces the initiative's mission, lists its programmes, links to a donation page and displays an image with alternative text.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Food for All Initiative</title>
</head>
<body>
    <h1>Food for All Initiative</h1>
    <h2>Our Mission</h2>
    <p>Our mission is to fight food insecurity by providing food to people in need.</p>

    <h2>Our Programmes</h2>
    <ul>
        <li>Food distribution</li>
        <li>School feeding</li>
        <li>Community farming</li>
    </ul>

    <a href="donate.html">Donate Now</a>
    <img src="bb.jpg" alt="Volunteers distributing food to families">
</body>
</html>

Keep the image file named bb.jpg in the correct folder if you want the image to display when this example is run separately.

1(d) — Ways of Applying CSS

Internal CSS

Internal CSS uses the <style> tag inside the HTML document's head section.

External CSS

External CSS uses a separate CSS file linked to the HTML document.

Recommendation

External CSS is best for a large multi-page government portal.

Justification

It allows many web pages to share one stylesheet, ensuring consistency and making maintenance easier.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Applying CSS</title>
    <style>
        body { font-family: Arial, sans-serif; }
    </style>
</head>
<body>
    <h2>Ways of Applying CSS in HTML</h2>
    <h3>1. Internal CSS</h3>
    <p>Internal CSS uses the style tag inside the head section.</p>
    <h3>2. External CSS</h3>
    <p>External CSS uses a separate CSS file linked to the HTML document.</p>
    <h3>Recommendation</h3>
    <p>External CSS is best for a large multi-page government portal.</p>
    <h3>Justification</h3>
    <p>It supports consistency and easier maintenance.</p>
</body>
</html>

1(e) — Student Registration Form

The form collects a student's name, gender and password, then provides a Register button.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Student Registration</title>
</head>
<body>
    <form>
        Student Name:
        <input type="text" name="studentName"><br>

        Gender:
        <input type="radio" name="gender" value="Male"> Male
        <input type="radio" name="gender" value="Female"> Female
        <br>

        Password:
        <input type="password" name="password"><br>

        <input type="submit" value="Register">
    </form>
</body>
</html>
