1(d) — Ways of Applying CSS

Ways of Applying CSS in HTML

1. Internal CSS

Internal CSS uses the <style> tag inside the HTML document's head section.

2. External CSS

External CSS uses a separate CSS file linked to the HTML document.

Recommendation

External CSS is best for a large multi-page government portal.

Justification

It allows many web pages to share one stylesheet, ensuring consistency and making maintenance easier.
