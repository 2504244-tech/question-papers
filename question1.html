Q1(d): Applying CSS

Internal CSS

Internal CSS is written inside a style element in the HTML document's head.

External CSS

External CSS is written in a separate CSS file and linked to the HTML document.

Recommendation

External CSS is recommended for a large government portal because many pages can share one stylesheet. This improves consistency and makes maintenance easier.
