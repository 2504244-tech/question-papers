Ordered list

Steps for online registration: create an account, enter details and submit the form.

Unordered list

Hospital services include outpatient care, maternity services and laboratory tests.

Description list

HTML is used to structure web pages. CSS is used to style web pages.

2(c) — Kenya Bank Portal: Hyperlinks

Absolute hyperlink

An absolute hyperlink uses the complete web address (URL) to link to another website. For example, linking to the Central Bank of Kenya.

Visit Central Bank of Kenya

Use: To link to external websites such as regulators and partner organisations.

Relative hyperlink

A relative hyperlink uses a file path to link to another page within the same website.

Example: <a href="staff.html">Open Staff Portal</a>

Use: To navigate between internal pages such as staff, loans and customer support.

Difference

An absolute hyperlink uses a complete URL, while a relative hyperlink uses a path based on the current page's location.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Kenya Bank Portal</title>
</head>
<body>
    <h1>Kenya Bank Portal</h1>
    <h2>1. Absolute Hyperlink</h2>
    <p>An absolute hyperlink uses the complete web address (URL).</p>
    <a href="https://www.centralbank.go.ke">Visit Central Bank of Kenya</a>
    <p>Use: To link to external websites.</p>

    <h2>2. Relative Hyperlink</h2>
    <p>A relative hyperlink uses a file path to link to another page within the same website.</p>
    <a href="staff.html">Open Staff Portal</a>
    <p>Use: To navigate between internal pages.</p>

    <h2>Difference</h2>
    <p>An absolute hyperlink uses a complete URL, while a relative hyperlink uses a path based on the current page's location.</p>
</body>
</html>

2(d) — Public Health Website: Alt Text

Alternative text describes an image for people who cannot see it or when the image does not load.

Consequences of missing alt text

  1. Visually impaired users: Screen readers cannot describe images, making health information difficult to access.
  2. Users with slow internet: If images fail to load, users may miss important health information.
  3. Search engines: Search engines have less information to understand and index the images.
  4. Users with limited literacy: Users who rely on images to understand health instructions may struggle to understand the information.

Solution

Add meaningful alt text, such as: “A healthcare worker educating patients about disease prevention.” This improves accessibility and understanding.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Public Health Website</title>
</head>
<body>
    <h1>Public Health Information - Kenya</h1>
    <img src="health.jpg" alt="A healthcare worker educating patients about disease prevention">
    <h2>Consequences of Missing Alt Text</h2>

    <h3>1. Visually Impaired Users</h3>
    <p>Screen readers cannot describe images, making health information difficult to access.</p>

    <h3>2. Users with Slow Internet</h3>
    <p>If images fail to load, users may miss important health information.</p>

    <h3>3. Search Engines</h3>
    <p>Search engines have less information to understand and index the images.</p>

    <h3>4. Users with Limited Literacy</h3>
    <p>Users who rely on images to understand health instructions may struggle.</p>

    <h2>Solution</h2>
    <p>Adding meaningful alt text improves accessibility and understanding.</p>
</body>
</html>

Keep health.jpg in the correct folder if you run this example as a separate page.
