Answers for parts (b) and (c).

3(b) — News Website Navigation

The navigation bar contains Home, News, Sports and Contact links. Flexbox spaces the links evenly, and a hover effect changes the link colour to orange.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>News Website</title>
    <style>
        nav {
            background-color: black;
            display: flex;
            justify-content: space-evenly;
            padding: 15px;
        }
        nav a {
            color: white;
            text-decoration: none;
        }
        nav a:hover {
            color: orange;
        }
    </style>
</head>
<body>
    <nav>
        <a href="home.html">Home</a>
        <a href="news.html">News</a>
        <a href="sports.html">Sports</a>
        <a href="contact.html">Contact</a>
    </nav>
</body>
</html>

3(c) — Climate Awareness in Kenya

This page uses Flexbox to place a quick-facts sidebar beside an article. A media query changes the layout to a column on screens 600 pixels wide or smaller.

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <title>Climate Awareness</title>
    <style>
        body {
            font-family: Arial, sans-serif;
        }
        .container {
            display: flex;
            gap: 20px;
        }
        aside {
            flex: 1;
            background: lightgreen;
            padding: 15px;
        }
        article {
            flex: 2;
            background: lightyellow;
            padding: 15px;
        }
        @media (max-width: 600px) {
            .container {
                flex-direction: column;
            }
        }
    </style>
</head>
<body>
    <h1>Climate Awareness in Kenya</h1>
    <div class="container">
        <aside>
            <h2>Quick Facts</h2>
            <p>Plant trees.</p>
            <p>Save water.</p>
            <p>Reduce pollution.</p>
        </aside>
        <article>
            <h2>Climate Change</h2>
            <p>Climate change affects people, animals and the environment.</p>
            <p>We should protect forests, conserve water and reduce waste.</p>
        </article>
    </div>
</body>
</html>
